Первичная настройка

Сначала создайте постоянный секрет для этого экземпляра приложения и добавьте его в Google Authenticator.

Google Authenticator

Секрет вашего экземпляра MaxSecure хранится локально как неэкспортируемый криптографический ключ.

Добавьте вручную в Google Authenticator
  1. Добавьте новый аккаунт.
  2. Выберите ввод ключа настройки вручную.
  3. Вставьте показанный Base32-ключ.
  4. Тип ключа: Time based.

Сброс удалит локальный TOTP-ключ. Сохранённые заметки этого экземпляра после этого открыть будет нельзя.

Заметок пока нет

Создайте заметку. Заголовок будет виден в списке, а содержимое откроется только после проверки Authenticator.

Новая заметка

При редактировании старый шифр-код заменяется новым только после успешной проверки кода и сохранения. Автосохранения нет.

Шифрование

Расшифровка

Модель защиты

  • Текст заметок шифруется существующей схемой AES-256-GCM.
  • Для каждого сохранения создаётся новая случайная 256-битная соль и nonce.
  • Постоянный TOTP-секрет хранится локально как неэкспортируемый HMAC CryptoKey.
  • Актуальный 6-значный TOTP-код проверяется перед открытием, сохранением и удалением заметки.
  • Сам TOTP-код в заметку не записывается.
  • Нет сервера, аналитики, CDN и сторонних библиотек.
  • Незавершённое редактирование не сохраняется автоматически.

Браузер не предоставляет универсальной гарантии аппаратной привязки IndexedDB. Для особо критичных данных нужен независимый криптографический аудит.

Локальная настройка

Сброс ключа сделает сохранённые шифр-коды этого экземпляра недоступными.

Все операции выполняются на этом устройстве.
